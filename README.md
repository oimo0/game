# PLAYROOM 03

ブラウザで遊ぶ50タイトルのゲームロビー。日本語の画面、ジャンル検索、端末内のベストスコア保存、タッチ操作に対応しています。

## 今回の再構築

ロビーのHTML/CSS、サムネイル生成、ゲームの起動・切替処理と3Dレースを新規実装しました。レースは5つの異なるコース、6台の車、3周制です。実際の位置・向き・速度を計算し、ハンドル、アクセル、ブレーキ、ドリフト、ニトロ、路外減速、車同士の接触、順序付きチェックポイント、順位、追従カメラ、ミニマップを実装しています。CPUも独立して走行します。

残る45タイトルは既存の2Dゲーム処理を引き継ぎ、不要なWebGL処理を除去して新しい起動基盤へ接続しました。50本すべてのゲームルールを新規実装した版ではありません。カタログは30種類のゲームモードとコース・ステージのバリエーションで構成されています。

## 起動

```sh
python3 -m http.server 8000
```

http://localhost:8000 を開いてください。3Dレースの初回起動ではThree.jsをjsDelivrから取得するため、ネット接続とWebGLが必要です。2DゲームとロビーはThree.jsの読込に依存しません。

GitHub Pagesを使う場合は、Settings → Pages → Deploy from a branchで、mainと/(root)を指定します。本変更はPagesの設定を変更しません。

## 操作

- レース: W/↑ 加速、S/↓ ブレーキ・後退、A/D/左右 ハンドル、Shift ドリフト、Space ニトロ、R コース復帰。
- その他: 起動前の画面にゲーム別の操作方法を表示します。
- Escで一時停止。別ウィンドウへ移った場合も一時停止します。
- スコアはブラウザ内に保存します。旧版の記録とは分けて保存します。

## 検証

```sh
npm test
```

Node.js 22以降を使用してください。外部パッケージのインストールは不要です。

70件のチェックを含みます。5コースのCPU完走、周回判定の順序、ニトロ残量、コース外復帰、45タイトルの開始・フレーム更新・描画呼出・一時停止・再開始とカタログ整合性を検証します。2D描画テストはCanvas APIの代替を使用し、WebGL描画やブラウザでの実プレイを保証するものではありません。

## 構成

- src/race/simulation.js: 描画から独立した走行計算とコース定義
- src/race/racing.js: 3Dワールド・車・カメラ・HUD
- src/runtime.js: ゲーム切替、リソース解放、3Dモジュールの遅延読込
- src/engine.js: 2Dゲーム
- src/art.js: カタログのSVGサムネイル
- src/main.js: ロビー、モーダル、入力、記録

## ゲーム別の操作

- レース: 左右ハンドル、アクセル・ブレーキ、ドリフト、ニトロを別ボタンで同時操作。
- 横スクロール: 左右移動とジャンプ。重力ステージだけ反転ボタンを追加。
- ラン: 左右スワイプでレーン変更、タップ・上スワイプでジャンプ。
- シューティング: スティック＋長押し連射、または画面をドラッグして移動・射撃。
- サバイバル: 全方向スティックとクールダウン付きダッシュ。
- 落ちもの: 左右長押し、回転、低速落下、即落下。スワイプにも対応。
- パズル: 盤面を直接操作。数独はマス選択＋数字パッド、地雷は旗モードを使用。
- リズム: 4つの演奏パッド、またはSpaceの単独タップ。
- 果物: タップか指でなぞる操作。

各ゲームの起動前に専用の説明を表示します。タッチ用移動パネルはタッチ端末・狭い画面で表示。数字入力・旗モードはPCでも表示します。ボタン外で指を離した場合、キャンセル、一時停止、画面切替時に入力を解放します。追加の入力テストはジェスチャー、同時押し、キー反復、入力解除と盤面操作を検証します。
