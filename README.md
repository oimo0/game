# PLAYROOM

[公開版を開く](https://oimo0.github.io/game/)

55タイトル・7ジャンルのブラウザゲーム集です。日本語ロビー、ジャンル検索、タッチ操作と端末内ベストスコア保存に対応しています。

## 新作：Deep Field

時間制限のない3D宇宙探索。太陽・8惑星・月を巡り、10個の観測記録を集められます。惑星へのワープ、視点回転、ズーム、自由飛行、時間停止・早送り、自動ツアー、衛星への追従カメラがあります。

外部ライブラリや画像の取得に依存しない専用描画です。WebGLでは解析的なレイと球の交差判定、手続き的な惑星表面、昼夜・雲・大気の縁の散乱風表現、土星の環と遮蔽を描画します。WebGLを使用できない端末では、透視投影とピクセル単位の球面照明によるCanvas描画へ自動切替します。互換描画の表面模様や光は簡略化されます。

**教育用の正確な天体シミュレータではありません。** サイズ、距離、公転速度、表面は見やすさを優先した演出です。Starlinkをイメージした72機・6軌道面の衛星群は合成軌道です。SpaceXの実機位置、現在の衛星数、ライブ映像、公式データではありません。

宇宙の新作はさらに4本：

- Lunar Descent：燃料、慣性、傾きを調節して3ステージの軟着陸。
- Orbital Engineer：加速・減速で目標軌道を8秒間維持。逆二乗の引力を使った簡易2D運動。
- Gravity Slingshot：ドラッグで彗星を発射し、惑星の引力でポータルを狙う3ステージ。
- Starlight Trail：数字順に星をつなぐ3種類の星座パズル。

## 操作

- 宇宙探索：ドラッグで視点、ピンチ・ホイール・＋−でズーム。惑星セレクトでワープ。左アナログスティックで周回と距離調節、自由飛行では移動。PCはWASD、Q/Eで惑星変更、Spaceで観測、Fで飛行、Tで時間、Rでツアー。
- レース：スマホは自動アクセルが初期ON。左スティックでハンドル、右手でブレーキ・ドリフト・ニトロ。自動アクセルOFFではスティック上下で加減速。PCはWASD/矢印、Shift、Space、Rでコース復帰。
- 横スクロール：左スティックの倒し具合で速さ調節、右ボタンでジャンプ。
- 射撃・サバイバル：全方向アナログスティック。射撃は長押し、ダッシュにはクールダウン。
- その他：各ゲームの開始画面に専用の説明を表示。盤面は直接タップ、リズムは4パッド、ランはスワイプ。
- Escで一時停止。ウィンドウから離れたときも一時停止。
- スティックとボタンは別の指で同時操作可能。指を離す、キャンセル、フォーカス解除、一時停止、ゲーム切替で入力を解除。

## 起動

```sh
python3 -m http.server 8000
```

http://localhost:8000 を開いてください。インストールやビルドは不要です。GitHub Pagesではmainのルートを公開します。

既存の5つのカートレースは通常Three.jsを使用します。取得失敗・8秒のタイムアウト・WebGL起動失敗時には、同じ走行計算と周回ルールのCanvas互換3Dに自動切替します。ロビー、2Dゲーム、新作の宇宙探索はThree.jsを取得しません。

## 構成と範囲

- src/space/model.js：天体・合成衛星軌道・カメラ・自由飛行
- src/space/gpu.js：専用WebGLシェーダー
- src/space/explorer.js：探索、互換描画、観測、ツアー、タッチ視点
- src/new/physics.js、src/new/games.js：新作4本のルール・描画
- src/race/：5コース、6台、3周のレース。車両運動、CPU、接触、ニトロ、順序付きチェックポイント、ミニマップ
- src/engine.js：従来の2Dゲーム45本。既存ルールを継承し、操作を改善
- src/controls.js：ゲーム別の操作パネルとアナログ入力
- src/runtime.js：ゲーム切替とリソース解放
- src/main.js、src/art.js：ロビーとサムネイル

55タイトルすべてを別々のルールで新規実装した版ではありません。従来のコース・テーマ違いを含む30モードに、5種類の新作を追加しています。宇宙探索はゲーム性のあるサンドボックスです。

## 検証

```sh
npm test
```

Node.js 22以降。外部パッケージ不要。100テストで、カタログ・操作・アナログ入力・キャンセル・2Dゲーム45本の開始と更新・レース5コースのCPU完走・起動フォールバック・新作の物理と進行・天体と衛星の位置・自由飛行・観測・全惑星への移動を確認します。Canvasテストには代替APIを使用しており、実機の描画品質を保証するものではありません。
